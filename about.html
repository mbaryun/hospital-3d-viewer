About This Project

A Web-Based Interactive 3D Hospital Room Viewer

📋 Project Overview

This project is an interactive web-based 3D application that presents a virtual hospital room environment. It was built as part of a web 3D application assignment, combining 3D modelling, interactive UI design, and dynamic content loading to create an immersive viewer experience.

The application allows users to load individual 3D hospital room objects, manipulate the scene through camera presets, control lighting, toggle wireframe mode, and trigger animations — all through an intuitive web interface.

🏗️ 3D Model Production

All 3D models were created from scratch using Blender, a professional open-source 3D authoring tool. Each model was built using low-poly geometry to ensure efficient rendering in the browser.

The following models were produced:

  • Hospital Bed — built from cube and cylinder primitives with mattress, pillow and headboard components.
  • Patient Monitor — screen body, emissive display face, stand and control panel.
